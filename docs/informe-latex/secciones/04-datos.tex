Un cambio de precio o kit del catálogo no modifica una venta anterior. La cantidad del componente ya incorpora cuántos kits contiene la línea y no debe multiplicarse dos veces.

\subsection{Claves restricciones y concurrencia}
Cada entidad tiene clave primaria. Las relaciones utilizan claves foráneas reales SKU y usuario tienen índices únicos dentro de sus tablas. El servicio comprueba también que un SKU no se repita entre producto y kit Pago tiene unicidad por pedido clave de idempotencia y referencia Devolucion es única por pedido y referencia MovimientoInventario utiliza la combinación producto referencia motivo RecepcionEvento tiene clave compuesta evento y suscriptor.

La transacción registra pago movimientos estado y Outbox de manera consistente. Las transacciones locales no se presentan como una garantía distribuida con una pasarela bancaria real \cite{transacciones}.

\subsection{Migración semilla y recuperación}
La migración InicialAlan y su snapshot se generaron para esta estructura de entidades. La inicialización aplica migraciones y una semilla idempotente con cinco productos dos kits cuatro cuentas y clientes de prueba. Un marcador evita que reiniciar la aplicación vuelva a crear datos borrados intencionalmente \cite{migraciones}.
