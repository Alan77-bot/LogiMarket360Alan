
\section{Anexos}
\subsection{Instalación ejecución y cuentas de demostración}
Abrir la solución en Visual Studio compatible y seleccionar LogiMarket.WinForms como inicio. El objetivo de los proyectos es .NET 8. El formato slnx requiere un SDK o IDE compatible. El proyecto WinForms también puede compilarse directamente desde su csproj.
\begin{lstlisting}[language={},numbers=none]
dotnet restore LogiMarket360Alan.slnx
dotnet build LogiMarket360Alan.slnx
dotnet run --project LogiMarket.WinForms
dotnet test tests/LogiMarket.Tests
dotnet tool restore
dotnet ef migrations list --project LogiMarket.Infrastructure
\end{lstlisting}
Las cuentas ficticias son admin ventas bodega y consulta con clave de demostración Demo123! La base se crea automáticamente y la contraseña se almacena con hash. La clave anterior no es una credencial personal.

\subsection{Reproducir las evidencias de formularios}
\begin{lstlisting}[language={},numbers=none]
powershell -File scripts/verificar_roles.ps1
powershell -File scripts/verificar_roles.ps1 -Escenario RevisionFlujo
\end{lstlisting}
Los ejecutores conservan bases e imágenes de prueba en tmp y no modifican la base de ejecución del usuario Para reiniciar una demostración manual cerrar la app y renombrar la carpeta de datos como respaldo. No borrar información que se quiera conservar.

\subsection{Origen de imágenes y código}
Las imágenes se copiaron de docs/evidencias/capturas del repositorio público sin alterar sus píxeles. El archivo imagenes/PROCEDENCIA.json registra el commit la URL y SHA256 de cada una. Los listados son fragmentos de archivos del mismo commit. No son capturas del editor.

Los archivos finales requeridos se denominan \ruta{APE04_LogiMarket360_APELLIDOS_NOMBRES.zip} y \ruta{APE04_Informe_APELLIDOS_NOMBRES.pdf}. Los nombres deben completarse cuando se faciliten los datos confirmados.
