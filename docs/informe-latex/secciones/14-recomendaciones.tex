
\section{Recomendaciones vinculadas con las conclusiones}
\begin{enumerate}[label=R\arabic*,leftmargin=1.2cm]
\item A partir de C1 conservar los escenarios numéricos y las instantáneas al ampliar el catálogo Agregar pruebas de una nueva política sin alterar los casos oficiales
\item A partir de C2 repetir restauración compilación y prueba cuando cambien referencias paquetes o migraciones Evitar entregar bin obj bases personales o credenciales reales
\item A partir de C3 preparar la sustentación recorriendo una clase participante su invocación y su prueba Capturar los bloques del IDE que pide la guía sin sustituirlos por imágenes decorativas
\item A partir de C4 ampliar los fallos controlados solo con colaboradores simulados y comprobar también los efectos que no deben ocurrir Mantener la autorización dentro de Application
\item A partir de C5 cerrar la revisión manual de accesibilidad y documentar futuras refactorizaciones cuando ocurran con evidencia antes y después No inventar defectos para llenar la tabla Completar los datos institucionales antes de entregar
\end{enumerate}
