\subsection{KISS DRY y YAGNI}
KISS mantiene las integraciones simuladas y los flujos visibles sin añadir servicios de nube no exigidos DRY se refleja en Ui en las transacciones reutilizables y en la base VistaPedidos usada por Cobro Despacho y Devoluciones YAGNI evita introducir pagos reales contenedores o fiscalidad no definidos por la práctica.

La organización de pruebas se revisó después de distribuir los casos por responsabilidad. Se retiraron 42 ayudas privadas sin uso y se ejecutó de nuevo la suite completa conservando 62 aprobadas. Esa limpieza no se utiliza como evidencia de 42 defectos ni de nuevos escenarios.

\subsection{Cómo localizar un cambio en la defensa}
Para una nueva promoción se modifica el conjunto de estrategias Para otro proveedor se implementa el puerto de cobro y su selección Para un campo persistido se revisan entidad caso de uso mapeo formulario y migración Para cambiar un permiso se revisan tanto PermisosVista como la autorización de Application. Cada modificación debe acompañarse de un caso que compruebe el resultado y sus efectos no permitidos.
