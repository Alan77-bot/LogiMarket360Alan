# LogiMarket360Alan

Proyecto nuevo construido por el estudiante, paso a paso, segun GUIA_APE_04.

## Estado actual

Solo estructura de cinco proyectos .NET 8 y archivos pendientes. Todavia no hay base de datos, pantallas funcionales, reglas, patrones ni pruebas implementados.

Abrir LogiMarket360Alan.slnx en Visual Studio. No se copio el codigo del proyecto anterior. Consultar docs/ESTRUCTURA.md para el inventario y el orden de aprendizaje.

El ejecutable WinForms tiene un punto de entrada minimo que termina sin abrir ventanas. Esto permite comprobar las referencias mientras construimos el sistema.

No se han instalado paquetes de EF Core, SQLite, DI ni xUnit; se agregaran y explicaran en su etapa. Tests es por ahora una biblioteca sin pruebas ejecutables.
