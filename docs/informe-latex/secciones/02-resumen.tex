
\section{Resumen ejecutivo}
LogiMarket es una aplicación de escritorio para comercializar accesorios de computación y kits anidados. Su flujo reúne clientes pedidos promociones inventario cobros simulados despacho entrega devolución total y trazabilidad. La implementación se organiza en cinco proyectos con C\# y .NET 8 utiliza Windows Forms para la presentación y EF Core 8 con SQLite para persistencia real \cite{guia,repo,winforms}.

La evidencia automatizada registra \textbf{62 pruebas aprobadas 0 fallidas y 0 omitidas} La matriz conserva los 38 escenarios oficiales y enlaza cada resultado con pruebas y archivos. La compilación desde un ZIP limpio terminó con cero errores y cero advertencias. El ejecutor de flujo confirmó la venta de Ana por USD 59.00 la salida de componentes la entrega y la devolución por USD 54.00 sin reembolsar el envío.

El repositorio contiene los 23 patrones GoF con participantes y recorridos de ejecución. No se presentan como ejemplos aislados se usan en construcción de pedidos composición de kits cálculo de promociones protección del cobro reacciones a eventos consultas y presentación de comprobantes.

\textbf{Límite de la evidencia} Las capturas proceden de formularios reales instanciados por ejecutores reproducibles Las comprobaciones visuales no equivalen a un recorrido manual exhaustivo de TAB foco y DPI Tampoco existe evidencia nueva suficiente de diez pares de refactorizaciones con prueba antes y después La existencia de una lista de riesgos no se utiliza para dar ese requisito por cumplido
