\subsection{Git refactorización y evidencia antes y después}
Se conservaron cambios reales por finalidad y ramas de implementación comentarios y publicación. Antes de publicar se anonimizaron autorías de contacto y rutas privadas conservando fechas mensajes y relaciones de los 43 commits previos. Los identificadores SHA cambiaron por esa limpieza. El código de 202 archivos de fuente y proyecto permaneció idéntico.

La guía exige al menos diez riesgos y una explicación de refactorización concreta con Git y prueba antes y después. La lista anterior cubre riesgos pero \textbf{no acredita diez pares nuevos de fallo y reparación} No se reconstruyen commits ni pruebas rojas retrospectivas para aparentar ese cumplimiento.

\subsection{Limitaciones verificables}
\begin{itemize}[leftmargin=1.2cm]
\item La revisión manual exhaustiva de TAB foco y DPI de monitor sigue pendiente
\item Las capturas de código del IDE no se sustituyen por los listados de este informe Ambos sirven para explicar pero son evidencias diferentes
\item Los pagos correos SMS y guías son simulados y los comprobantes no tienen validez tributaria
\item No se declara un SLA de respuesta ni una reducción de memoria total del proceso a partir de Flyweight
\item La persistencia con otro contenedor DI no se presenta como una comprobación manual de reiniciar Windows
\item La autoría y comprensión individual deben sustentarse en la defensa El documento no certifica que toda la implementación haya sido escrita manualmente por el participante
\end{itemize}
